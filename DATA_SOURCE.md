# Dataset access

**Source:** Yeasmin, T. (2023), *Potato Leaf Disease Based on Weather Details*, Kaggle.

**Original source URL:** https://www.kaggle.com/datasets/tamima1530/potato-leaf-disease-based-on-weather-details

The data file is intentionally **not included** in this repository. Download it from the original provider, then place the original Excel data in the root of this project as `Disease with Weather.xlsx`. The notebook uses the fields `Temperature`, `Humidity`, `Visibility`, and `Disease in number`. For the version used in the manuscript, there are 4,020 usable rows, of which 1,954 are Late Blight (0) and 2,066 Early Blight (1).

The authors should confirm that the externally hosted data have not changed and cite the dataset in the manuscript.
